# T-072 — The first screen changes font, size and position while it loads (Flutter app)

Owner report (13 Nov, iPhone, two screenshots 17:22, saved here): the intro page is inconsistent — the first frame shows a SERIF "BRICKFORD" with a wider "SELF-BUILT UNIVERSITY" and the crest slightly lower; a moment later the same screen shows a SANS "BRICKFORD", smaller subtitle, crest slightly higher and larger. The fade in/out between them is inconsistent. This is a bug fix (allowed during the feature freeze); Flutter app only (the website has no splash).

## What I found (read-only, main 38f5435+)
- Stage 1: static HTML `#boot` in app/web/index.html: crest 112x125 CSS px, wordmark `700 24px Georgia` (serif) letter-spacing .14em, rule 40x1 margin 9px, subtitle 11px 600 .2em system sans, `transition: opacity .25s`, removed on the `flutter-first-frame` event.
- Stage 2: Flutter `SplashApp` (app/lib/main.dart) → `CrestLockup(height: 132)` (app/lib/widgets/crest.dart): crest 132 tall, wordmark `display()` = Playfair Display at 0.2*h = 26.4px, rule 0.3*h wide, subtitle Inter 0.085*h = 11.2px. Different crest size, wordmark size, font family (Georgia vs Playfair) and vertical centring from stage 1.
- Likely extra cause of the SANS wordmark in the second screenshot: bundled fonts (assets/fonts/playfair, inter) load lazily, so the first Flutter frame paints with the engine's FALLBACK font before Playfair arrives, then reflows. Verify by capturing frames; do not assume.
- Stage 3: Splash → Shell swap; check whether it has any transition.
